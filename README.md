# SEPL — Suvidhinath Electronics Pvt. Ltd.

Premium corporate website for Suvidhinath Electronics Private Limited.

## Tech Stack

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS v4
- Framer Motion
- GSAP + ScrollTrigger
- Lenis Smooth Scroll
- Lucide Icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Customization

Update company content in `src/lib/data.ts` — director info, contact details, projects, testimonials, etc.

Replace placeholder images with actual company photos in the `public/` folder.
